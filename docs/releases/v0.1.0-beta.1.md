# v0.1.0-beta.1 — draft release notes

Draft only. No tag or GitHub release has been created. Publish only after owner authorization and the release checks in [release preparation](../BETA_RELEASE_PREPARATION.md).

Semester OS brings a university timetable, courses, attendance, plans, notes and study progress into a personal, accountless semester workspace. ECU Computer Science students are the primary and most deeply tested audience; other universities, faculties, programs, levels and semesters are supported through the generalized importer and editable academic context.

- Choose ECU for enhanced recognition of selected document layouts, or Another university for the generalized English timetable importer. Review locally extracted PDF/image courses and sessions before generating a workspace, or enter details manually. Academic context is optional and editable, with no preselected university, faculty, program, level or term. Generic imports do not receive ECU metadata; missing fields stay unknown. Fresh users can explore a labelled demo or open an empty workspace.
- Keep academic records in browser IndexedDB, with validated backups, recovery points and explicit workspace deletion. There is no student backend, cloud OCR or application telemetry.
- Use Today, Schedule, course workspaces, manual attendance, Planner, Progress and a persistent study timer.
- Install the PWA and reopen core pages offline after shell preparation. Prepare the separate extraction tools before relying on offline imports.
- Choose 13 curated themes or Custom. Midnight includes moonlit stars; Campus has moving daylight; Focus has quiet breathing illumination. Prism's protected renderer is preserved.
- Use keyboard search/navigation, desktop and compact layouts, and OS/manual reduced-motion controls. First-run locked navigation provides accessible explanations and keeps unavailable routes out of keyboard/palette selection.
- The documented validation baseline is 265 passing tests in 21 files, alongside lint, strict TypeScript, production builds, dependency audits and source/privacy checks. These checks are not a security or accessibility certification.

The live beta includes the published university-generalization work. Recognition can be wrong and must be reviewed against official documents; unfamiliar layouts may require manual corrections, and English OCR does not transcribe Arabic image text. Backups are unencrypted; browser storage can be cleared or evicted. Physical-device installation, longer sessions and unassisted student testing need broader coverage. Operator/contact and draft-policy review remain release tasks.
