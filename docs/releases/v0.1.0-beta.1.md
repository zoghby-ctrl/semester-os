# v0.1.0-beta.1 — draft release notes

Draft only. No tag or GitHub release has been created. Publish only after owner authorization and the release checks in [release preparation](../BETA_RELEASE_PREPARATION.md).

Semester OS brings a university timetable, courses, attendance, plans, notes and study progress into a personal, accountless semester workspace.

- Review an ECU or generic English timetable from a PDF/image using local extraction and OCR, or enter details manually. Fresh users can also explore a labelled demo or open an empty workspace. Workspace navigation clearly unlocks after setup.
- Keep academic records in browser IndexedDB, with validated backups, recovery points and explicit workspace deletion. There is no student backend, cloud OCR or application telemetry.
- Use Today, Schedule, course workspaces, manual attendance, Planner, Progress and a persistent study timer.
- Install the PWA and reopen core pages offline after shell preparation. Prepare the separate extraction tools before relying on offline imports.
- Choose 13 curated themes or Custom. Midnight includes moonlit stars; Campus has moving daylight; Focus has quiet breathing illumination. Prism's protected renderer is preserved.
- Use keyboard search/navigation, desktop and compact layouts, and OS/manual reduced-motion controls. First-run locked navigation provides accessible explanations and keeps unavailable routes out of keyboard/palette selection.
- Automated tests, lint, strict TypeScript, production builds, dependency audits and source/privacy checks validate the beta. These checks are not a security or accessibility certification.

Recognition can be wrong and must be reviewed against official documents. Backups are unencrypted; browser storage can be cleared or evicted. Physical-device installation, longer sessions and unassisted student testing need broader coverage. Operator/contact and draft-policy review remain release tasks.
